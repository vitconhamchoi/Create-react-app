# 09. React thiếu gì so với Angular và phải tự bổ sung gì

## Những thứ Angular làm tốt hơn ngay từ đầu
- structure rõ
- DI built-in
- router built-in
- forms built-in mạnh
- HttpClient built-in
- RxJS integration sâu
- convention đồng bộ hơn

## Những thứ React không cho sẵn
- kiến trúc app chuẩn duy nhất
- form strategy chuẩn
- state strategy chuẩn
- data fetching strategy chuẩn
- guard/interceptor style chuẩn

## Mày phải tự chọn
Một stack React tương đối ổn thường sẽ là:
- React
- React Router
- TanStack Query
- react-hook-form
- Zod
- Zustand hoặc Redux Toolkit nếu cần

## Vấn đề thật
React không làm mày ngu.
Nó chỉ bắt mày tự chịu trách nhiệm nhiều hơn.
Nếu team yếu, codebase React dễ loạn hơn Angular.

## Chốt
Angular mạnh vì đầy đủ.
React mạnh vì linh hoạt.
Nhưng linh hoạt luôn đi kèm giá phải trả.
