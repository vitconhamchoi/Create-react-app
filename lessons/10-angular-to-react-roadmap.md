# 10. Roadmap thực chiến để chuyển từ Angular sang React

## Giai đoạn 1. Hiểu lõi React
Học chắc:
- JSX
- props
- state
- render cycle
- useEffect
- event handling

## Giai đoạn 2. Biết cách làm app thật
Học tiếp:
- routing
- form handling
- data fetching
- service layer
- custom hooks

## Giai đoạn 3. Tự dựng stack hợp lý
Nên thử stack này:
- React
- TypeScript
- Vite
- React Router
- TanStack Query
- react-hook-form
- Zod

## Giai đoạn 4. Mapping từ Angular sang React
Tự trả lời được các câu:
- Angular service sang React dùng gì
- Angular lifecycle sang React nghĩ kiểu gì
- Angular form sang React xử lý sao
- Angular router guard sang React làm sao
- Angular state stream sang React chọn gì

## Giai đoạn 5. Làm mini project
Nên tự làm lại một app từng làm bằng Angular, ví dụ:
- todo app có filter
- CRUD user
- login + protected route
- dashboard gọi API

## Câu chốt cuối
Muốn chuyển từ Angular sang React mà không bị ngu thì đừng học React như syntax mới.
Hãy học nó như một cách tổ chức UI khác, ít framework hơn và đòi hỏi tự chủ hơn.
