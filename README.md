# React Learning Series for Angular Developers

Bộ bài học này dành cho người đã code Angular và muốn chuyển sang React mà không bị hụt chân vì React ít opinionated hơn.

Mục tiêu:
- hiểu React theo cách so sánh với Angular
- biết React thiếu gì so với Angular và phải tự bù bằng gì
- code được app thực chiến, không chỉ biết JSX

## Cách học

- Đọc theo thứ tự 1 -> 10
- Mỗi bài đều có so sánh Angular vs React
- Tập trung hiểu cách nghĩ, không chỉ syntax

## Kết luận nhanh

Angular cho mày framework hoàn chỉnh.
React cho mày core UI library và bắt mày tự quyết nhiều thứ hơn.

Muốn chuyển sang React không bị ngu thì phải học:
- state
- effect
- render cycle
- reference identity
- hook mindset
- cách tự tổ chức app khi framework không làm hộ
